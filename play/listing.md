# Google Play adatlap – ServerDeck

## English (en-US) – alapértelmezett

**App name (max 30):**
ServerDeck: SSH server manager

**Short description (max 80):**
Monitor and manage your Linux servers over SSH. No agent, no account.

**Full description (max 4000):**

ServerDeck looks after your Linux servers from your phone: how they are doing, which services are up, what the logs say, and the one command that has to run right now.

It talks to each server over plain SSH and nothing else. There is no agent to install, no port to open and no account anywhere: the phone signs in the way ssh from a laptop would and runs ordinary commands.

OVERVIEW
• CPU, memory and disk at a glance, turning amber and red as they fill up
• The last three minutes of CPU and memory as a chart
• Network traffic, load average, every disk and swap
• Host name, distribution, kernel and uptime

SERVICES
• systemd units: running, failed or all, with their status and last journal lines
• Restart, reload, stop and start, each asking first and showing the exact command
• Docker containers: state, health, logs, restart, stop and start

LOGS
• The system journal, a service's journal or any log file, followed live
• Errors in red, warnings in amber, a filter and an errors-only switch

COMMANDS AND TERMINAL
• Saved commands per server or shared, a tap away
• Live output, the time taken, a stop button and the exit code
• A full interactive terminal with the keys a phone keyboard lacks: esc, tab, ctrl, arrows

MONITORING
• Background checks every 15 minutes to 6 hours, per server
• A notification when a server goes down and when it is back
• Uptime over 24 hours, 7 days and 30 days, and a log of outages
• No false alarms for a blip or for the phone's own lost network

SECURITY
• Ed25519 keys made on the phone, or your own OpenSSH, RSA or ECDSA keys
• Install a key on a server with one password sign-in
• Private keys and passwords in the Android Keystore
• Host key fingerprints checked, with a clear warning when one changes
• Optional fingerprint, face or PIN lock

TRY IT FIRST
No server at hand? Tap "Try the demo" on the empty server list: four simulated servers on which every screen works.

PRIVACY
ServerDeck collects nothing. No account, no analytics, no ads. It talks to nothing but your servers.

Open source (GNU AGPL-3.0): github.com/szabolevi98/serverdeck

Languages: English, Hungarian, German, Spanish and French.

## Magyar (hu-HU)

**Alkalmazás neve (max 30):**
ServerDeck: SSH szerverkezelő

**Rövid leírás (max 80):**
Linux szervereid figyelése és kezelése SSH-n. Agent és fiók nélkül.

**Teljes leírás (max 4000):**

A ServerDeck a telefonodról tartja szemmel a Linux szervereidet: hogy vannak, mely szolgáltatások futnak, mit írnak a logok, és lefuttatja azt az egy parancsot, aminek most kell lefutnia.

Minden szerverrel sima SSH-n beszél, semmi mással. Nincs telepítendő agent, nincs megnyitandó port és nincs fiók sehol: a telefon úgy lép be, ahogy a laptopról az ssh, és hétköznapi parancsokat futtat.

ÁTTEKINTÉS
• CPU, memória és lemez egy pillantásra, borostyán, majd piros színnel, ahogy telnek
• Az utolsó három perc CPU- és memóriahasználata grafikonon
• Hálózati forgalom, terhelés, minden lemez és a swap
• Gépnév, disztribúció, kernel és üzemidő

SZOLGÁLTATÁSOK
• systemd egységek: futó, hibás vagy mind, állapottal és az utolsó naplósorokkal
• Újraindítás, újratöltés, leállítás és indítás, mindegyik rákérdez és megmutatja a pontos parancsot
• Docker konténerek: állapot, health, logok, újraindítás, leállítás és indítás

LOGOK
• A rendszernapló, egy szolgáltatás naplója vagy bármely logfájl, élőben követve
• Hibák pirossal, figyelmeztetések borostyánnal, szűrő és csak-hibák kapcsoló

PARANCSOK ÉS TERMINÁL
• Mentett parancsok szerverenként vagy közösen, egy koppintásra
• Élő kimenet, futásidő, leállítás gomb és kilépési kód
• Teljes interaktív terminál a telefonról hiányzó billentyűkkel: esc, tab, ctrl, nyilak

FIGYELÉS
• Háttérellenőrzés 15 perctől 6 óráig állítható időközönként, szerverenként
• Értesítés, ha egy szerver leáll, és amikor újra elérhető
• Rendelkezésre állás 24 órára, 7 és 30 napra, és a kiesések naplója
• Nincs téves riasztás egy pillanatnyi akadásért vagy a telefon saját hálózatvesztéséért

BIZTONSÁG
• A telefonon készült Ed25519 kulcsok, vagy saját OpenSSH, RSA és ECDSA kulcsok
• Kulcs telepítése a szerverre egyetlen jelszavas belépéssel
• Privát kulcsok és jelszavak az Android Keystore-ban
• Host key ujjlenyomat-ellenőrzés, egyértelmű figyelmeztetéssel, ha megváltozik
• Opcionális ujjlenyomat-, arc- vagy PIN-zár

PRÓBÁLD KI
Nincs kéznél szerver? Az üres szerverlistán koppints a „Demó kipróbálása” gombra: négy szimulált szerver, amelyen minden képernyő működik.

ADATVÉDELEM
A ServerDeck nem gyűjt semmit. Nincs fiók, nincs analitika, nincs reklám. Csak a szervereiddel beszél.

Nyílt forráskódú (GNU AGPL-3.0): github.com/szabolevi98/serverdeck

Nyelvek: magyar, angol, német, spanyol és francia.
